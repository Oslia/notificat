# Notificat

猫をモチーフにした、M5Stack CoreS3 向けの小型 IoT アラームクロックである。320 × 240 のタッチ画面に現在時刻と天気を表示し、アラーム、週間予報、Wi-Fi、地域設定をそれぞれ独立した機能として提供する。

> [!IMPORTANT]
> このプロジェクトは生成 AI（OpenAI Codex）との協働によって開発している。開発者が製品要件と判断基準を提示し、AI を設計案の検討、C/C++ 実装、リファクタリング、障害調査、文書作成に利用した。AI の出力をそのまま品質保証とせず、ビルド結果と実機動作を開発者が確認する方針である。

## 主な機能

- ホーム画面で現在時刻と現在の天気を表示
- 最大 8 件のアラーム、曜日指定、一回のみの実行、スヌーズ
- CoreS3 スピーカーによるアラーム音と全画面通知
- Open-Meteo を利用した現在値、3 時間間隔、7 日間の天気予報
- 周辺 Wi-Fi の検索、接続、切断、保存済みネットワークへの再接続
- 地域ごとのタイムゾーン、座標設定と Wi-Fi 接続後の SNTP 時刻同期
- 下端からのスワイプで表示するスクロール可能なアプリランチャー
- 猫のローディング画面と低負荷なダークテーマ

## アーキテクチャ

UI と機能ロジックを分離している。`*App` と `*View` は LVGL の描画と入力だけを担当し、アラーム、天気、時刻、ネットワークなどの状態はサービスが所有する。バックグラウンドタスクは LVGL を直接操作せず、`SystemEventBus` と値コピーのスナップショットを介して UI に変更を通知する。

```text
AppShell / App
      │ commands / snapshots
      ▼
Feature services
      │ hardware / network contracts
      ▼
Platform services and providers
```

クラス関係、起動処理、天気更新、アラーム発火の設計図は [UML 設計図](docs/uml.md) にまとめている。より詳しい責務分担は [アーキテクチャ](docs/architecture.md) を参照する。

## ビルド

ESP-IDF の環境を有効化したシェルで実行する。

```console
idf.py set-target esp32s3
idf.py build
idf.py -p <PORT> flash monitor
```

FATFS イメージはビルド時に `rsc/` から生成され、ファームウェアと一緒に flash 対象へ含まれる。既存の `sdkconfig` は CoreS3、PSRAM、LVGL、LCD バッファ向けに調整済みである。

## 設定と操作

1. 起動後、下端から上へスワイプしてランチャーを開く。
2. `Settings` から地域と Wi-Fi を設定する。
3. Wi-Fi 接続後に SNTP 同期と天気取得が非同期で開始される。
4. `Alarm` で時刻と曜日を設定する。曜日を選択しない場合は一度だけ実行される。

小型画面のため、不要なスクロールや全画面アニメーションを避けている。操作と描画の詳細は [UI ガイドライン](docs/ui_guidelines.md) に記載している。

## AI 利用について

このリポジトリでは、AI を次の用途に使用している。

- 要求の整理と設計上の選択肢の比較
- UI と機能サービスを分離するアーキテクチャの作成
- ESP-IDF / FreeRTOS / LVGL を使用するコードの実装とレビュー
- スタック不足、内部 RAM 不足、SPI DMA エラーなどの調査と対策案作成
- 日本語の要件、設計、運用文書の作成

一方、製品の目的、採用する機能、UX の方向性、外部サービス利用の可否は開発者が決定している。AI が生成したコードにも誤りや未確認の前提が含まれる可能性があるため、実機検証、セキュリティ評価、ライセンス確認は別途必要である。
