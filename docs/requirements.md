# Notificat プロダクト要件

## プロダクトの方向性

- 猫のキャラクターを中心コンセプトとする IoT デバイス。
- 起動時に `rsc/notificat.bmp` をローディング画面として表示する。
- コンテンツ機能は、アラーム時計と天気の独立したアプリで構成する。あるアプリの内部状態や実装は、他のアプリに直接依存してはならない。

## 必須機能

### ホーム

- 起動後の基本画面として、現在時刻と選択地域の現在の天気概要を同時に表示する。
- 詳細操作はホームに詰め込まず、各専用アプリまたはシステム設定へ移動する。

### アラーム時計

- 繰り返しアラームを最大 8 件まで追加、時刻変更、有効化／無効化、削除できる。
- アラームごとに日曜日から土曜日まで任意の曜日を選択できる。毎日、平日、週末も同じ曜日設定で表現する。
- 曜日を選択しないアラームは次の該当時刻に一度だけ実行し、発火後に自動で無効化する。
- アラーム設定は NVS に保存し、再起動後も保持する。
- システムの選択地域に対応したローカル時刻でアラームを判定する。
- アラームは別のアプリを表示している間もバックグラウンドで判定・通知される。
- 発火時は CoreS3 のスピーカーと全画面表示で通知する。スピーカー初期化に失敗した場合も画面操作で停止できる。
- 発火画面から停止、または 5 分間のスヌーズを選択できる。
- 操作されないアラームは 10 分後に自動停止する。
- システム時刻が未確定の場合は誤発火を避けるため判定を保留する。

### 天気

- 選択地域の現在の天気をホーム画面と天気アプリに表示する。
- 天気状態は文章ではなく `rsc/weather/` のアイコンで表示し、気温や降水確率などの数値情報を併記する。
- 天気アプリに、現在時刻から 3 時間間隔の 24 時間予報を表示する。
- 天気アプリに、当日を含む 7 日間の予報を表示する。
- Wi-Fi 接続中は、最後の取得成功から 1 時間ごとに情報を更新する。
- 地域設定を変更した場合は、次の定期更新を待たずに新しい地域の情報を取得する。
- Wi-Fi が再接続された場合は、未取得または期限切れの情報を取得する。
- 取得に失敗した場合も UI を停止せず、5 分後に再試行する。直前に取得済みの情報があれば表示を維持する。
- CoreS3 本体には GPS を前提とせず、「位置変更」はシステム設定で選択した地域の変更として扱う。
- 天気データの提供元とライセンス表記を画面または製品情報に表示する。

### ネットワーク

- ネットワーク管理はコンテンツアプリとは別のシステム管理機能とする。
- 周辺の接続可能な Wi-Fi を検索する。
- ユーザーが SSID を選択し、パスワードを入力して接続できる。
- 現在の接続状態を確認し、ネットワーク接続を解除できる。
- 保存済みの Wi-Fi 設定がある場合は、起動後に自動再接続を試みる。
- Wi-Fi 接続後に、システム時刻を SNTP で同期する。

### 地域設定

- システム設定画面で地域を選択し、設定を再起動後も保持する。
- 選択した地域のタイムゾーンをシステム時刻の表示に適用する。
- 選択した地域を現在の天気、時間別予報、週間予報の取得対象に使用する。

## 画面構成

- 基本画面はホームダッシュボードとし、現在時刻と現在の天気概要を同じ画面に表示する。
- 天気アプリでは、時間ごとの予報と 7 日間の予報を切り替えて表示できる。
- 画面上部は、すべての画面で共通表示されるグローバルステータスバーとする。
- ステータスバーにはネットワーク状態と有効なアラーム件数を表示する。今後、時刻、バッテリー、通知状態を追加できるようにする。
- アプリのコンテンツは、ステータスバー以外の画面全体を使用する。
- 画面下部から上へスワイプすると、アプリ選択メニューを表示する。
- アプリ選択メニューはスクロール可能で、下方向へ引き下げて閉じられる。
- ランチャーに `Home`、`Alarm`、`Weather`、`Settings` を表示する。Wi-Fi は独立アプリにせず `Settings` 内で管理する。

## 非機能要件

- ネットワーク処理と画面描画は、UI を停止させないよう非同期で処理する。
- Wi-Fi、時刻、通知などのデバイス全体の状態は、システムサービスが所有する。
- 機能アプリは、システムサービスを介してのみグローバル状態を取得または要求する。
- サービス層は LVGL API を呼び出さず、UI に状態スナップショットまたは操作結果を提供する。
