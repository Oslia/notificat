# Notificat UI ガイドライン

## 目的

320×240 の小型画面でも、短時間で内容を確認し、確実に操作できる UI を提供する。

## 視覚設計

- 全体背景は深いチャコール `#0F1115` とし、起動画面の猫が持つ線画の印象を引き継ぐ。
- サーフェスは `#181C22`、補助サーフェスは `#242A33` とする。
- 基本文字はクリーム `#F5EEDF`、補助文字はグレー `#9CA3AF` とする。
- 強調色はコーラル `#F07A5A`、キャラクターの補助色はピンク `#D98C9C` とする。
- 角丸カードと細い境界線で情報をまとめる。描画負荷の高い影と半透明レイヤーは使用しない。
- 猫の顔記号 `=^.^=` はヘッダーやランチャーなど限られた場所に置き、情報の可読性を妨げない。
- 画面切り替えは即時とし、全画面アニメーションを使用しない。ランチャーだけは不透明な単色背景のまま短い位置アニメーションを許可する。
- 天気状態の名称は表示せず、`rsc/weather/` のアイコンで伝える。気温、降水確率、湿度、風速など判断に必要な数値は残す。

## 操作設計

- 基本画面では、現在時刻と現在の天気を最優先で表示する。
- 詳細情報は専用アプリに分け、1 画面に 1 つの判断を求める。
- タップ領域は可能な限り高さ 40px 以上を目安にする。
- 画面最下部 16px の上方向スワイプだけをアプリランチャー用に予約する。
- 画面上部 24px はグローバルステータスバーとして共通表示する。
- Wi-Fi 設定は独立アプリではなく、`Settings` の項目から開く。
- アプリランチャーは内容を縦スクロールでき、先頭位置から下へ引くと閉じる。
- パスワード入力用キーボードは入力欄にフォーカスがある間だけ表示する。現在の試作仕様では大型の数字キーパッドを使用する。

## 描画性能

- スクロールはランチャー、一覧、予報リスト、入力欄など必要なウィジェットだけに許可する。時刻ローラーは LVGL 固有のドラッグ処理を使用し、一般オブジェクト用のスクロールフラグを追加しない。
- 一覧の慣性スクロールと端の弾性効果を無効にし、指を離した後の連続再描画を避ける。
- 天気タブは横スワイプで移動せず、タブボタンを押して即時に切り替える。
- カードは不透明な単色で描画し、影、グラデーション、全画面フェード、半透明スクリーンを避ける。
- ランチャーの表示は 150 ms、終了は 120 ms とし、30 fps 設定で必要以上の中間フレームを生成しない。
- PNG の再デコードを抑えるため、PSRAM 上の LVGL メモリから 128 KiB の画像キャッシュと 8 件のヘッダーキャッシュを使用する。
